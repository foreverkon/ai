# 从研究到文章

从已有计算、图、笔记与文献中寻找中心问题：结果需要解释什么，哪些比较可以让读者理解这个解释，最终形成什么认识。把这些选择写成树的文章与章节概述。

先呈现文章和章节，再展开段落，最后展开句子；在每层取得研究者对当前范围的实际确认。段落的句子可以分批审查，完整约定范围确认后填写正文。对既有稿件的定向修改，可明确以一节或一段为范围。

每次讨论聚焦当前子树的任务、顺序和关键选择。确认记录引用实际反馈。树的意图或顺序改变时重开相关审查；正常展开与保持意图的语言修改复用已有确认。

并行协作时，主 agent 先确定共同的科学问题与分支任务；子 agent 返回建议意图、来源依据、补研究方案及尚未解决的选择。主 agent 统一处理相互冲突的科学解释并合并当前树，研究者仍在上述三个层次确认论证。

## 填写过程中发现缺口

| 写作需要 | 动作 |
|---|---|
| 结果已有，比较不易读 | 用实际数据制作回答该问题的图 |
| 关键趋势受数值设置影响 | 补目标量的收敛或敏感性计算 |
| 当前诊断无法区分候选机制 | 提出可判别的计算，或改写为当前材料能支持的解释 |
| 新结果改变中心解释 | 修改结果、摘要与结论的相关意图 |
| 某支暂时没有可填写结果 | 保留该意图并记录补研究任务，推进其他段落 |

在`research/tasks.json`中记必要信息：稳定任务ID、涉及的节点、科学问题、所需输入、计算/作图方案、输出与判断标准。方案应说明不同结果分别如何改变论证。按 [项目目录](project-structure.md) 将补计算放在`research/TASK-01/`、图放在`figures/FIG-01/`，已有科研目录直接复用。已有授权和可用工具时执行，结果成为填写材料并登记证据；缺少输入时说明具体缺项。

按段落读取意图、相关前提和实际来源，填句子，再从形成的段落检查是否实现原任务。需要增加独立沟通动作时，在树中增加句子意图。意图与内容的关系由实际阅读判断。

完成约定范围后，交付当前树或正文及有实际影响的未决问题。下一步计算应回答已识别的研究问题。
