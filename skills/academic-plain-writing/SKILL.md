# 学术语言

直接说明研究对象、采用的方法和得到的结果。用学科通用术语和普通书面语写作。

## 用词

使用完整词语和明确的动宾结构。写“判断是否收敛”“固定参数”“比较计算结果”，避免“判收”“钉参数”“拉结果”这类临时拼出的简称。同一概念保持同一名称，不为避免重复轮换近义词。

禁止用以下黑话表达研究操作或评价：

| 禁用表达 | 改写方向 |
| --- | --- |
| 赋能、加持 | 说明提供了什么条件、实现了什么功能 |
| 落地、抓手 | 写明应用对象、实施方法或具体措施 |
| 钉死、拉通、打通 | 写明固定、连接或统一的具体对象 |
| 对齐认知、统一口径 | 写明采用的定义、假设或评价标准 |
| 技术底座、模型栈、技术栈 | 直接列明模型、软件或算法及其用途 |
| 闭环、生态、组合拳（泛泛描述工作） | 说明步骤之间的关系或方法如何结合 |
| 颗粒度、打法、痛点（泛指研究问题） | 写明分析尺度、研究方法或具体问题 |
| 护城河、降维打击、颠覆性突破 | 改为有依据的差异或比较结果；空泛赞美直接删除 |

根据上下文恢复实际含义，不逐词替换。原文没有提供具体信息时，保持原有概括程度，不补造细节。

学科已有的术语按其正式含义使用，例如序列对齐、闭环控制、调用栈、生态系统。保留符号、单位、代码标识符和规范缩写。新概念需要定义；给普通操作起一个新名字不能使它成为专业术语。

## 句子与段落

- 从研究问题、论点或结果开始。删除“值得注意的是”“下面展开说明”“一句话总结”等空泛引导。
- 直接陈述结论。删除只用于抬高语气的“不是……而是……”“不仅……更是……”。真实的方法差异、否定判断和概念辨析应明确写出比较对象与依据。
- 禁止用“等同于／不等同于”作泛泛评价或预防性的辩解。直接说明实际关系、差异或结论范围，不用“意味着／并不意味着”等近义句式重复同一空话。数学等价关系、定义和论证必需的概念区分应准确保留。
- 每段围绕一个问题组织。拆开修饰关系不清的长句，合并重复陈述，保留因果、条件和转折关系。
- 用事实说明贡献。删除“具有重大意义”“开辟全新局面”等没有具体内容的评价，不额外添加宏大意义。
- 用实验范围表达适用条件，用证据表达确定程度。重复的自我辩解可以删去，实际局限应在相关结论处说清楚。
- 摘要概括研究问题、方法和主要结果；结论回答研究问题。避免把正文重新列举一遍或用口号收尾。

## 标点与衔接

- 避免连续几句都用破折号或分号接出第二层意思，也避免一句中反复追加插入语。能独立成句的内容分开写；需要联系的内容明确表达因果、条件、并列或转折关系。
- 避免反复使用冒号追加解释，例如“原因是：……”“这意味着：……”“关键在于：……”。将有用的解释写入句子，删去重复解释和预告。
- 不把破折号统一替换成分号或冒号。重新组织句子后通读段落，避免换一种标点继续串接长句，也不要把连贯论述切成零碎短句。
- 根据标点的作用判断，不设每段固定配额。保留列举、公式引出、复杂并列项中的必要标点，以及数值范围、英文复合词、引用格式和代码中的符号。

## 学术准确性

保留数据、公式、单位、引用、比较基准和实验条件。保留负面结果、性能代价和影响解释的限制，不因它们削弱叙事而删去。

结论的强度与证据一致。“相关”不能改成“导致”，“提示”不能改成“证明”，“计划开展”不能改成“已经完成”。“显著”若表示统计意义，须有相应检验依据；没有量化结果时，不编造数字替换程度词。

引用原话和正式名称保持准确。被动句、第一人称、必要的限定词和正常的单字术语按学科习惯使用。

## 英文写作

使用原稿语言直接编辑，保持学术语体和作者习惯。上述词义、句式和标点规则同样适用于英文。

- 检查 `is equivalent to`、`is not equivalent to`、`equates to`、`does not equate to` 等表达。修辞性的等同或否定改为具体陈述；正式等价关系和必要的概念区分保留。
- 删除 `it is worth noting that`、`a groundbreaking paradigm`、`unlock the potential` 等无信息的铺垫或夸赞。`leverage`、`empower`、`synergy` 等词用于泛泛宣传时，写明实际动作或关系。
- 检查反复出现的 em dash、semicolon 和解释性 colon。拆分或重组分句时保持逻辑，不用逗号直接拼接两个独立句子。
- 保留 `may`、`suggest`、`is consistent with` 等与证据相符的限定，以及必要的被动句、冠词和术语。不要为缩短文字改变含义或降低正式程度。

## 示例

原句：以自适应网格为抓手，赋能剪切层模拟；网格根据速度梯度加密。

改写：根据速度梯度对网格进行自适应加密，用于模拟剪切层流动。

原句：该方法实现了性能跃迁：在相同误差容限下，相比基线方法，计算时间缩短20%，峰值内存增加8%。

改写：在相同误差容限下，该方法相比基线方法的计算时间缩短20%，峰值内存增加8%。

原句：结果提示，在测试的雷诺数范围内，速度场与温度场之间可能存在更强的耦合。

处理：保留。术语、范围和不确定性均有实际含义。

原句：A lower training error does not equate to better generalization—the test error remained unchanged; the training error decreased by 10%.

改写：The training error decreased by 10%, while the test error remained unchanged.

原句：The result has a limitation: the evaluation used one dataset. The next step is clear: we plan to test two additional datasets.

改写：The evaluation used one dataset. We plan to test two additional datasets.

## 交付

对照原文检查事实、限定条件和论证关系，再通读语句是否连贯。默认交付正文；用户要求时附修改说明。成稿只包含文章所需内容，标题、注释和说明中也不写修改过程或已经放弃的措辞。
